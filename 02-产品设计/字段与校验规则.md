# 字段与校验规则

[[00-MOC/访客系统总览|返回总览]]

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 姓名 | 文本 | 是 | 1-50 个字符，去除首尾空格 |
| 手机号 | 文本 | 是 | 中国大陆手机号基本格式校验；服务端再次校验 |
| 公司 | 文本 | 是 | 1-100 个字符 |
| 被访人 | 文本 | 是 | 1-50 个字符 |
| 来访事由 | 文本 | 是 | 1-200 个字符 |
| 同行人数 | 整数 | 是 | 0-50，默认 0 |
| 车牌号 | 文本 | 否 | 最多 20 个字符，允许新能源车牌格式 |

## 系统字段

| 字段 | 说明 |
| --- | --- |
| visit_id | 服务端生成的唯一 ID |
| created_at | 服务端记录的提交时间，统一存储时区 |
| status | `normal` 或 `hidden` |
| source | 固定值 `qr_h5` |

## 数据原则

客户端校验只改善体验，不能替代服务端校验。所有字符串在展示时进行 HTML 转义，防止注入；导出前固定列顺序并处理 CSV 公式注入风险。
