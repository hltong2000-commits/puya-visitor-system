# 安全控制清单

[[00-MOC/访客系统总览|返回总览]]

- [ ] 全站启用 HTTPS，HTTP 自动跳转。
- [ ] 后台账号使用强密码和密码哈希。
- [ ] 登录失败限速，必要时临时锁定。
- [ ] H5 提交接口限流和防重复提交。
- [ ] 服务端执行所有字段校验。
- [ ] 查询使用参数化 SQL，排序字段使用白名单。
- [ ] 页面输出做 HTML 转义。
- [ ] CSV 导出处理公式注入风险。
- [ ] 手机号在列表中脱敏。
- [ ] 导出、隐藏、登录等动作写入审计日志。
- [ ] 数据库、备份和日志目录限制访问权限。
- [ ] 备份恢复演练通过。
- [ ] 上线前完成依赖漏洞扫描和基础渗透测试。
