# 普冉半导体外来客户扫码登记访客系统设计

## 已确认需求

- 独立 Web/H5 入口。
- 使用者允许使用手机设备扫码，并通过手机浏览器完成登记；不要求电脑或 App。
- 只做登记，暂不需要员工审核。
- 登记写入数据库成功后，页面显示“登记成功”和本次登记摘要，包括登记时间、姓名、完整手机号、公司、被访人、来访事由、同行人数和车牌号。该摘要仅在当前成功页面显示，刷新后消失；登记成功即完成流程，不需要前台或员工确认。
- 采用精简字段：姓名、手机号、公司、被访人、来访事由、同行人数、车牌号（选填）。

## 设计结论

保持单体业务边界：H5 表单 + Web API + 轻量后台 + 数据库。目标部署采用 CloudBase 静态托管、同源 `/api/*` 网关、单个 Node.js HTTP 云函数和 CloudBase PostgreSQL；本机开发保留 SQLite，Vercel + Neon 仅作为迁移期间的临时回退。首版不引入复杂权限中心、门禁、短信或 CRM 集成。后台提供日期/关键词查询、详情、CSV 导出和软隐藏能力。

## 数据与安全

服务端二次校验、HTTPS、后台鉴权、手机号脱敏、限流、防重复提交、参数化查询、审计日志和备份为上线基线。完整手机号只在访客本次成功页面和有权限的后台详情中显示；刷新后摘要消失，系统不提供公开历史查询接口。建议在线查询覆盖 180 天，正式保留期限由法务/信息安全负责人确认。

## 成功标准

客户可在手机浏览器完成登记；只有数据库写入成功后才显示与保存内容一致的 8 项登记摘要；登记成功无需前台或员工确认；无效数据不能入库；前台可在 10 秒内找到当天记录；导出结果可被 Excel 正常打开；网络失败不误报成功。
