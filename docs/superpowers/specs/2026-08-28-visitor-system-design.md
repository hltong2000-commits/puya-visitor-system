# 普冉半导体外来客户扫码登记访客系统设计

## 已确认需求

- 独立 Web/H5 入口。
- 使用者允许使用手机设备扫码，并通过手机浏览器完成登记；不要求电脑或 App。
- 只做登记，暂不需要员工审核。
- 登记成功后只显示成功提示，前台在后台列表查询。
- 采用精简字段：姓名、手机号、公司、被访人、来访事由、同行人数、车牌号（选填）。

## 设计结论

采用单体 Web 服务：H5 表单 + Web API + 轻量后台 + 数据库。首版不引入复杂权限中心、门禁、短信或 CRM 集成。后台提供日期/关键词查询、详情、CSV 导出和软隐藏能力。

## 数据与安全

服务端二次校验、HTTPS、后台鉴权、手机号脱敏、限流、防重复提交、参数化查询、审计日志和备份为上线基线。建议在线查询覆盖 180 天，正式保留期限由法务/信息安全负责人确认。

## 成功标准

客户可在手机浏览器完成登记；无效数据不能入库；前台可在 10 秒内找到当天记录；导出结果可被 Excel 正常打开；网络失败不误报成功。
