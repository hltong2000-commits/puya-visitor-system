# 访客数据视图

[[00-MOC/访客系统总览|返回总览]]

本页展示知识库中与访客系统相关的页面状态，不代表生产系统实时访客数据。

```dataview
TABLE WITHOUT ID
  file.link AS "页面",
  type AS "类型",
  updated AS "更新日期",
  data_quality AS "证据口径"
FROM "访客系统知识库"
WHERE contains(tags, "访客系统")
SORT updated DESC
```

若将来把生产访客数据接入 Obsidian，应单独建立脱敏导出文件，禁止把完整手机号直接写入知识库。
