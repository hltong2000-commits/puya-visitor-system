# 验收标准

[[00-MOC/访客系统总览|返回总览]]

## 功能

- [x] 使用手机设备扫码可在手机浏览器打开登记页。
- [x] 登记流程不要求安装 App、使用电脑或注册客户账号。
- [x] 七个登记字段符合 [[02-产品设计/字段与校验规则]]。
- [x] 必填、手机号、同行人数和长度校验有效。
- [ ] 登记写入数据库成功后显示“登记成功”和登记时间、姓名、完整手机号、公司、被访人、来访事由、同行人数、车牌号 8 项摘要。
- [ ] 成功摘要仅在当前页面显示，刷新后消失；系统不提供公开历史查询接口，也不需要前台或员工确认。
- [x] 后台可按日期和关键词查询。
- [x] 后台可查看详情并导出 CSV。
- [x] 隐藏记录不出现在前台默认列表。

## 质量与安全

- [x] 网络失败不会误报成功。
- [x] 重复点击不会产生重复记录。
- [x] 未登录不能访问后台数据。
- [x] 列表手机号脱敏，导出权限受控。
- [x] 日志和限流已验证；HTTPS、备份需部署环境验收。

## CloudBase 上线验收

- [ ] 静态页面、同源 `/api/*` 网关和 Node.js HTTP 云函数部署成功。
- [ ] `/api/health` 返回 `database: cloudbase-postgres`，数据写入 CloudBase PostgreSQL。
- [ ] 成功摘要与后台查询到的记录完全一致。
- [ ] 最终固定二维码指向已验证的 CloudBase HTTPS 登记首页。
- [ ] 微信真机扫码能够打开页面、提交登记并显示完整摘要。
- [ ] 已记录免费环境续期时间并建立资源点和流量配额检查。

## 性能基线

在预期并发下，登记提交接口 P95 响应时间不超过 2 秒；后台当天查询在 10 秒内完成并展示结果。
