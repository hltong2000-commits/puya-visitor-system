# 验收标准

[[00-MOC/访客系统总览|返回总览]]

## 功能

- [x] 使用手机设备扫码可在手机浏览器打开登记页。
- [x] 登记流程不要求安装 App、使用电脑或注册客户账号。
- [x] 七个登记字段符合 [[02-产品设计/字段与校验规则]]。
- [x] 必填、手机号、同行人数和长度校验有效。
- [x] 成功提交只显示成功提示，不生成访客凭证。
- [x] 后台可按日期和关键词查询。
- [x] 后台可查看详情并导出 CSV。
- [x] 隐藏记录不出现在前台默认列表。

## 质量与安全

- [x] 网络失败不会误报成功。
- [x] 重复点击不会产生重复记录。
- [x] 未登录不能访问后台数据。
- [x] 列表手机号脱敏，导出权限受控。
- [x] 日志和限流已验证；HTTPS、备份需部署环境验收。

## 性能基线

在预期并发下，登记提交接口 P95 响应时间不超过 2 秒；后台当天查询在 10 秒内完成并展示结果。
