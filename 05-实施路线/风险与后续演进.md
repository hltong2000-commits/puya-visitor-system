# 风险与后续演进

[[00-MOC/访客系统总览|返回总览]]

| 风险 | 影响 | 首版应对 |
| --- | --- | --- |
| 二维码被替换或张贴错误 | 客户无法登记或数据流向错误 | 张贴前核对域名，定期巡检二维码 |
| 手机号等个人信息泄露 | 隐私和合规风险 | HTTPS、脱敏、最小权限、保留期限 |
| 网络或服务器故障 | 无法登记 | 纸质应急表、备份和监控 |
| 前台不会查询 | 现场效率下降 | 极简列表、短培训、操作手册 |
| 需求快速膨胀 | 项目延期 | 以 [[01-业务方案/MVP范围与非目标]] 为变更基线 |

## 演进顺序建议

1. 员工审核和消息通知。
2. 访客状态、离场登记和统计。
3. 黑名单与风险提示。
4. 门禁、打印访客证和会议室系统对接。

每次演进都应重新评估个人信息范围、权限和数据保留策略。
