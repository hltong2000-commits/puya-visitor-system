# 访客登记业务流程

[[00-MOC/访客系统总览|返回总览]]

## 目标

让外来客户在到达厂区或前台后，通过固定二维码快速提交来访信息，前台能够按日期和关键词查询记录。

## 主流程

1. 前台在入口、接待区或访客登记牌张贴固定二维码。
2. 客户使用手机扫码打开 H5 登记页；系统不要求电脑、App 或客户账号。
3. 客户填写 [[02-产品设计/字段与校验规则|精简登记字段]]并提交。
4. 系统进行必填项、手机号、同行人数和长度校验。
5. 校验通过后写入访客记录。
6. 登记写入数据库成功后，页面显示“登记成功”和本次登记摘要，包括登记时间、姓名、完整手机号、公司、被访人、来访事由、同行人数和车牌号；登记成功即完成流程，不需要前台或员工确认。
7. 登记摘要仅在当前成功页面显示，刷新后消失；系统不提供公开历史查询接口，也不生成访客二维码或取件凭证。
8. 前台可登录后台列表，按日期、姓名、公司、手机号或被访人查询记录。

## 异常处理

| 场景 | 系统行为 |
| --- | --- |
| 必填项缺失 | 在对应字段下方提示，保留已填写内容 |
| 手机号格式错误 | 阻止提交并提示格式要求 |
| 网络中断 | 提示提交失败，允许重新提交；不得显示成功 |
| 重复点击提交 | 提交按钮进入处理中状态，避免重复写入 |
| 短时间内同手机号重复登记 | 提示可能重复，允许用户确认后再次提交 |
| 后台查询无结果 | 显示空状态和筛选条件，不能误报系统故障 |

## 非流程事项

首版不包含员工确认、访客证打印、门禁放行、黑名单拦截、短信通知和会议室预约。
