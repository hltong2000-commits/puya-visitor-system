# 数据模型

[[00-MOC/访客系统总览|返回总览]]

## visitors 表

| 列 | 类型建议 | 约束 |
| --- | --- | --- |
| id | UUID/整数 | 主键 |
| name | VARCHAR(50) | 非空 |
| mobile | VARCHAR(20) | 非空，建议加索引 |
| company | VARCHAR(100) | 非空 |
| host_name | VARCHAR(50) | 非空 |
| visit_reason | VARCHAR(200) | 非空 |
| companions | INTEGER | 0-50 |
| vehicle_plate | VARCHAR(20) | 可空 |
| created_at | TIMESTAMP | 非空 |
| status | VARCHAR(20) | `normal`/`hidden` |
| source | VARCHAR(20) | `qr_h5` |

## admin_users 表

保存后台账号、密码哈希、角色、启用状态和最近登录时间。密码只保存 Argon2id 或 bcrypt 哈希，不保存明文。

## audit_logs 表

保存登录、查询、导出、隐藏记录等操作的操作者、动作、目标记录、时间和来源 IP（按公司隐私政策决定是否保留）。

## 索引建议

为 `created_at`、`mobile`、`company`、`host_name` 建立查询所需索引；不要为每个可能的模糊查询盲目加索引。
